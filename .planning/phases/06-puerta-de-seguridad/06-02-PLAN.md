<objective>
**Como** operador del hub, **quiero** que las respuestas lleven una CSP conservadora y HSTS, **para** que un script inyectado no pueda ejecutar la API con mi sesión y para que el navegador no degrade a HTTP.

Aplica la discreción de CONTEXT para SEC-04: CSP con nonce por petición y `'strict-dynamic'` desde `src/proxy.ts` solo para documentos (la página ya es `force-dynamic`), CSP mínima de API en `next.config.ts`, y HSTS emitido por la aplicación con `max-age=15552000` sin `includeSubDomains` ni `preload`. Se aplica (no Report-Only): no hay sumidero de informes y crearlo exigiría una ruta POST nueva que habría que declarar y limitar; en su lugar el e2e escucha `securitypolicyviolation`. La reversión de la CSP es borrar `src/proxy.ts`.

Alcance: no toca rutas, guards ni límites de cuerpo (06-01, 06-04, 06-05). `style-src` conserva `'unsafe-inline'` porque hay 13 atributos `style` dependientes de datos que se serializan en el HTML (RESEARCH); no se añade `upgrade-insecure-requests` (Playwright y el desarrollo usan http://localhost y HSTS cubre el resto).
</objective>

## Trust Boundaries

| Límite | Intercambio |
| --- | --- |
| Navegador a documento | El HTML servido ejecuta scripts con la sesión del operador: una inyección de script alcanzaría la API con esa sesión. |
| Aplicación a proxy TLS | HSTS solo se respeta sobre HTTPS; la aplicación emite y Nginx Proxy Manager o Tailscale Serve transportan. |
| Navegador a API | Las respuestas JSON no son documentos y no necesitan cargar recursos. |
